
# ToyStore — Інтернет-магазин іграшок

## 1. Опис проєкту

ToyStore — це вебзастосунок для продажу іграшок через інтернет. Користувачі зможуть переглядати каталог товарів, дізнаватися інформацію про іграшки, додавати товари до кошика та оформлювати замовлення.

## 2. Проблема, мета та цільова аудиторія

### Проблема
Покупцям не завжди зручно шукати іграшки у звичайних магазинах. Інтернет-магазин дає змогу переглядати товари та оформлювати замовлення онлайн.

### Мета
Створити зручний інтернет-магазин іграшок із каталогом товарів, кошиком і можливістю оформлення замовлень.

### Цільова аудиторія
- Батьки, які купують іграшки для дітей.
- Родичі та друзі, які шукають подарунки.
- Користувачі, які хочуть купувати іграшки онлайн.

## 3. Ролі користувачів

- **Гість** — переглядає каталог і сторінки товарів.
- **Зареєстрований користувач** — переглядає товари, працює з кошиком та оформлює замовлення.
- **Адміністратор** — керує товарами та переглядає замовлення.

## 4. Основні функції та сторінки

### Основні функції
- Перегляд каталогу іграшок.
- Пошук і фільтрація товарів.
- Перегляд інформації про товар.
- Додавання та видалення товарів із кошика.
- Реєстрація та авторизація користувачів.
- Оформлення замовлень.
- Керування товарами та замовленнями адміністратором.

### Основні сторінки
- Головна сторінка.
- Каталог іграшок.
- Сторінка товару.
- Кошик.
- Сторінки реєстрації та авторизації.
- Сторінка оформлення замовлення.
- Панель адміністратора.
